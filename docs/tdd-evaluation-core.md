# 条件別の評価器と再集計できる試行記録

対象: TXT-02、EVAL-01、EVAL-04、A-12、A-13。本人による実験は実施していない。

## 受け入れ例

- 正解・生座標・選んだ行を分離し、後から入力オブジェクトを変更しても試行の記録が変わらない。
- 候補距離超過でも有効な生座標は保存する。無効座標・中断の候補は null。
- 候補なし・中断を含む全試行を率の分母とし、未観測の率・百分位を 0 にしない。
- 同じモデル・画面・配置条件だけで座標誤差を集計し、条件不明も欠落させない。
- CSV の先頭 12 列を維持し、JSON と同じ正解・候補・試行時の環境を再取得できる。
- viewport 変更・再開の前後を別の条件として JSON に保持し、公開集計にも条件混在を表示する。

## Red / Green

初期の Red / Green は Node.js 禁止の指示前に実行した記録である。以下の旧コマンドは現在の実行手順ではない。禁止指示後の実行環境は Deno に切り替えた。

| 対象 | Red の観測 | Green の観測 |
| --- | --- | --- |
| 試行スナップショット (`node --test tests/runner.test.ts`) | 14 件中、新しい 4 件が失敗。候補の保持・生座標のコピーが不足 | 14 件成功 |
| 座標と結果の評価 (`node --test tests/evaluation.test.ts`) | stub に対し 8 件中 7 件失敗、空入力 1 件成功 | 8 件成功 |
| 条件分割 (`node --test tests/evaluation-report.test.ts`) | stub に対し 6 件中 4 件失敗、コピー・空入力 2 件成功 | 6 件成功 |
| CSV (`node --test tests/trial-csv.test.ts`) | 5 件中 4 件失敗、空入力 1 件成功 | 5 件成功 |
| JSON の版と空の評価 (`playwright test --grep "interrupted coordinate"`) | 期待 schemaVersion 2 に対して 1。既存画面の JSON 配線が未更新 | 対象 1 件成功 |
| 公開集計の条件表示 (`deno test --no-check --no-prompt tests/evaluation-report.test.ts`) | 7 件中、新しい 1 件が失敗。条件情報を共有文面に含める関数が空 | 7 件成功 |

期待値は固定の入力・別途計算した距離と順位・独立した CSV 行で定めた。実装関数で期待値を生成していない。条件キーは環境の各フィールドを明示し、プロパティの挿入順に依存しない。共有文面は結果プレビュー・コピー・Issue で共通にした。

## 実行環境と測定の境界

現在の手順は `deno ci`、`deno task check`、`deno task build`、`deno task browser:install`、`deno task test:browser`。通常のユニットテストはファイル・ネットワーク・環境変数・子プロセスの追加権限なしで動く。コンパイラは Deno で TypeScript を実行し、ビルドは Deno で Vite の API を呼ぶ。ブラウザ試験は Deno のハーネスから Chromium を起動する。Node.js / npm / Playwright の Node ワーカーを実行しない。

座標誤差は行の正解点からの CSS px 距離であり、視線精度の実証値ではない。応答時刻を推論・描画遅延として集計しない。既存の診断 JSON とは別に行試行レポートを版管理し、画像・音声・連続視線データを公開集計へ追加していない。実カメラの精度・負荷は未測定である。

検証結果（2026-10-31）: Deno 2.9.8 で通常・Worker 型検査、104 ユニットテスト、9 ブラウザシナリオ、同梱資産を含む Vite ビルドが成功した。ブラウザの全経路はファイルを更新しない条件で再実行し、9 / 9 成功。初回の並行した設定更新中の試験では1件失敗したため、成功扱いには含めていない。GitHub CI の結果は PR の Checks を参照。
